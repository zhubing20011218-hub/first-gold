# 05 商品库

6 种商品，放在 `src/products/`。开局时给玩家 3 张卡：走量型、利润型、高风险型各一种。

**这里的数值全部是设计值（等级 C），不是真实数据。** 以后会根据项目负责人的核对和模拟结果调整。调整时只改这份数据，不改代码。

## 一、每种商品的字段

```ts
interface Product {
  id: string;
  kind: "volume" | "margin" | "risky";   // 走量型 | 利润型 | 高风险型
  costFen: number;              // 进价，每件
  weightG: number;              // 打包后的重量
  volumeCm3: number;            // 打包后的体积，立方厘米。用来算本土店的仓储费
  moq: number;                  // 起订量
  minPriceSen: number;          // 最低售价
  refPriceSen: number;          // 参考售价（市场上的普通价格）
  maxPriceSen: number;          // 最高售价
  elasticityE2: number;         // 价格敏感度乘以 100。150 表示贵 10%，订单少 15%
  organicPerDayMilli: number;   // 不投广告时每天的订单，单位是千分之一单
  adClickPoolPerDay: number;    // 市场上每天最多能买到的点击数
  baseCpcFen: number;           // 平时的市场参考出价，每次点击
  adCvrBp: number;              // 广告点击变成订单的比例
  returnBp: number;             // 退货率
  seasonBp: [number, number, number, number];   // 四个季节的市场热度倍数：1 到 3 月、4 到 6 月、7 到 9 月、10 到 12 月
  badReviewCount: number;       // 每年会遇到几次差评
  supplierMonthlyCap: number;   // 供应商每个月最多能供多少件
  bulkQtyBase: number;          // 批发询价单的基础件数
  bulkRefPriceSen: number;      // 市场批发参考价，每件
  scores: {                     // 卡片上显示的 5 个评分，1 到 5
    demand: number;             // 需求
    unitProfit: number;         // 每单利润
    capital: number;            // 占用资金
    afterSales: number;         // 售后风险
    competition: number;        // 竞争
  };
}
```

商品的中文名字和介绍放在 `src/text/zh.ts`，用 `id` 对应。
