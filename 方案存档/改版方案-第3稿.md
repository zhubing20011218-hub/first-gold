## 一、参考图告诉我们什么

| 参考图里的 | 在我们的游戏里 |
|---|---|
| 中心一个起点 | 义乌的小仓库：你带着 ¥50,000 开张 |
| 从中心往外的很多条路 | 不同的经营路线（卖什么、怎么卖） |
| 路上的小节点（橙、绿、蓝三种颜色） | 一个个要做决定的时刻，颜色表示是普通决定、机会还是危机 |

**这正好解决了你前面说的几个问题：**
- **没有闯关感**：每走一步，地图上就往外推进一格。
- **没有惊喜**：下一格是什么颜色，要看你的选择和这一段经营的结果。
- **玩完就没了**：地图上还有一堆灰色的问号结局没解锁，想再玩一次。

## 二、一局怎么玩（5 分钟以内）

```
开场 20 秒 → 5 个节点，每个大约 45 秒 → 结局 40 秒  ≈ 4 分 45 秒
（全部跳过动画，大约 3 分钟）
```

每个节点都是同一个节奏：

| 顺序 | 画面 | 时间 |
|---|---|---|
| 1. 走到节点 | 地图上的小店主沿着路走到下一格，镜头推进 | 3 秒 |
| 2. 局势 | 一张卡：现在发生了什么。危机和惊喜用**翻卡**揭开 | 5 秒 |
| 3. 做决定 | 2 到 3 个选项，每个写清楚要花多少钱、可能有什么结果 | 15 到 20 秒 |
| 4. 看结果 | 镜头进入卡通的小世界：货在走、单在来、钱在涨或者在掉，数字滚动 | 10 到 15 秒 |
| 5. 分叉 | 结果好，走向绿色的路；结果差，走向蓝色的危机。地图上亮起新的路 | 3 秒 |

## 三、这棵树（草稿）

### 3.1 五个节点，对应跨境电商的五个关键时刻

把十一步流程压成五个**最影响结局的决定**，其他步骤在动画里自动完成，不让玩家操作：

| 节点 | 跨境电商里的哪一步 | 要决定什么（例子） |
|---|---|---|
| ① 开张 | 选品 + 物流 | 三条路线选一条：<br>A. 小商品、跨境直发、走量（手机壳）；<br>B. 时尚服饰、开海外仓做本土店（头巾）；<br>C. 专做批发大单（B2B） |
| ② 引流 | 引流 | 广告猛砸 / 找达人直播 / 慢慢做自然流量 |
| ③ 突发 | 惊喜和危机（翻卡） | 翻开才知道：爆款视频、台风封港、价格战、大客户上门……每种有 2 到 3 种应对 |
| ④ 大促 | 大促 + 履约 | 双 11（或者开斋节）备多少货：全押 / 适量 / 不参加。全押时有**打包小游戏** |
| ⑤ 最后一步 | 扩张 | 扩张（开新国家、加新商品）/ 稳住 / 把店卖掉 |

省掉的步骤：
- 上架、定价、客服、回款、风控，不让玩家单独操作；
- 它们的效果仍然算进钱里，结局复盘里会提到。

### 3.2 怎么分叉：选择 + 结果，两样一起决定

- **只看选择**：玩家点哪个就走哪条路，结局可以背下来，第二次玩就没意思了。
- **选择 + 结果**（推荐）：
  - 同样选"广告猛砸"，钱算下来赚了，就走向绿色的路（机会）；
  - 亏了，就走向蓝色的路（危机）。
- 结果用现在已经做好、检查过的经营模型算：真实的佣金、运费、广告、大单，**钱的算法完全保留**。
- 运气由开局的编号决定：同一局再来一次运气一样，只换决定，可以看到"换一个选择，结局会怎样"。

### 3.3 十二个结局（宝石）

| # | 结局 | 大概怎么走到 | 净资产 |
|---|---|---|---|
| 1 | 百万爆款王 | 走量 + 广告猛砸 + 爆款视频 + 大促全押 | ¥1,000,000 以上 |
| 2 | 品牌出海 | 海外仓 + 达人 + 稳步扩张 | ¥1,000,000 以上 |
| 3 | 批发大亨 | 专做大单 + 每张都按时交货 | ¥1,000,000 以上 |
| 4 | 大促一夜暴富 | 前面一般，大促全押并且打包打得好 | ¥1,000,000 左右 |
| 5 | 稳稳的小老板 | 每一步都选稳的 | ¥300,000 到 ¥600,000 |
| 6 | 见好就收 | 赚到一些后把店卖掉 | ¥400,000 到 ¥800,000 |
| 7 | 压货清仓 | 大促备货太多，没卖完 | 亏一半左右 |
| 8 | 价格战两败俱伤 | 和对手比降价 | 回到本钱附近 |
| 9 | 大单违约 | 接了交不出的大单 | 赔光 |
| 10 | 现金流断了 | 钱都压在货和广告上，回款没跟上 | 破产 |
| 11 | 被平台封店 | 本土店风险一直不管 | 封店 |
| 12 | 隐藏结局：东南亚之王 | 前面四步都走对，最后扩张到多个国家 | ¥3,000,000 以上 |

- 好结局 5 个（含隐藏），中间的 2 个，坏结局 5 个。
- 坏结局也要有意思：每个都是真实卖家会踩的坑，会讲清楚坑在哪里。

## 四、结局画面：这一局的"解法"

1. **你的结局**：宝石亮起，印章，净资产，一句话。
2. **你走的路**：地图上高亮你走的那条路，每个节点写一句"你在这里做了什么，赚了 / 亏了多少"。
3. **关键的一步**：哪一步改变了结局。只说换一个选项会走到另一个结局，不说是哪个，让玩家自己再走一次去发现。
4. **收集**：已解锁 3 / 12 个结局，其他是灰色的问号。
5. **按钮**：同一局再试一次、换一条路、保存纪念海报。

## 六、心理学（调动情绪）

| 做法 | 为什么 |
|---|---|
| 一开始就看到整棵树和 12 个问号 | 好奇心和收集欲：想知道别的结局是什么 |
| 走一步亮一格 | 有进展的感觉，每 45 秒就有一个小高潮 |
| 翻卡揭开突发事件 | 不确定的奖励最让人上瘾 |
| 结果决定走绿路还是蓝路 | 紧张：同一个选择也可能翻车 |
| 大促全押时的打包小游戏 | 最刺激的一段，自己的手速影响结果 |
| 结局写"换一步就能到百万" | 差一点就成功，马上想再来一次 |
| 坏结局讲清楚坑在哪 | 输了也学到东西，不会只觉得被骗 |

起伏要公平：运气由开局编号定好，不偷偷针对玩家。

## 八、需要 calmness 定的事（全部定了再开始）

### 已经定了（2026-11-21）

- 分叉：**选择 + 结果一起决定**。
- 结局：**12 个，含 1 个隐藏**。
- 现在的"两年 8 个季度、三个功能区"的界面：**去掉**，只保留钱的算法。
- 金额：**起步 ¥50,000，目标 ¥1,000,000**。
- 设备：**评委用电脑玩**。按电脑屏幕设计，手机能打开就行，不专门优化。
- calmness 说明了参考图的意思：重点不是地图长什么样、走几步，而是**这个游戏的灵魂：选择不同的经营方式，一路经营到底，走到不同的结局**。地图的形状、一局做几次决定这些细节由我来定，只要一局在 5 分钟以内。

- **神秘感**（calmness 看了第一轮示意图后定的）：
  - 地图上不能写每条路是什么、通向哪个结局。
  - 没走过的圆点和 12 个结局在地图上全是一样的问号桶，外圈飘着云。
  - 只有自己这一局走过的路是金色、有颜色。
  - 解锁的结局只在"结局收集"里出现名字，不标在地图上。
  - 结局画面的"关键的一步"只说"换一个选择会走到另一个结局"，不说是哪个、多少钱。
  - 做决定时的提示也不提结局的名字。
- **地图：整棵树一开始就淡淡地摆着，走到哪里亮到哪里**（calmness 看了两轮示意图后定的）：
  - **一开始**：整棵树就画出来了，是淡紫色的虚线和小圆圈，像一朵蒲公英。从中心分成 3 条主干，一层层分叉，一共 54 条路线，越往外越淡，外圈飘着云。这样玩家一眼就知道路很多、结局很多，但看不清每条路是什么、通向哪里。
  - **选一条**：这一条变成金色，小店主走过去；从这个点长出的下一层分支亮起来（金色、会跳），可以点；同一层没选的变淡。
  - **第 3 步**：由经营结果决定，变成绿色（机会）或蓝色（危机）。
  - **最后**：选完以后，结局的金桶才在路的尽头长出来，并写上名字。
  - 地图上不写路线名字，也不写结局名字（见上一条"神秘感"）。只有自己走过的点下面有一个小标签，写自己选了什么。
- 画风：卡通、可爱、浅色。calmness 看过第一轮示意图，说可以。
