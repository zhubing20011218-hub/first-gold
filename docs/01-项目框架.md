# 01 项目框架

## 一、技术

| 项 | 用什么 | 说明 |
|---|---|---|
| 语言 | TypeScript，开启 `strict` | |
| 界面 | React | 只用函数组件 |
| 构建 | Vite | 打包结果是纯静态文件 |
| 样式 | Tailwind CSS | |
| 测试 | Vitest | |

| 动画 | Motion | 任务 01 不装，用到时再装 |
| 弹出层、滑块、提示 | Radix 的三个没有样式的基础件 | 任务 06 才装。见 `docs/12` 第一节 |
| 世界的画面 | three.js | 任务 06 才装。只用来画世界，见 `docs/10` |

- 版本用安装当天的稳定版。装好后，把主要依赖的版本号写进 `README.md`。
- 不使用：后端、数据库、登录、路由库、现成的整套界面组件库、图标库、外部的 3D 模型文件。
- 界面这一块完整的框架见 `docs/12-界面框架和体验设计.md`。
- 字体用系统自带的字体，不从网上加载字体。

## 四、分层

| 文件夹 | 可以引用 | 不可以引用 |
|---|---|---|
| `src/params` | 无 | 其他所有文件夹 |
| `src/engine` | `src/params` 的类型 | `ui`、`scene`、`staff`、`text`、React、浏览器接口 |
| `src/products` | `src/engine` 的类型 | `ui`、`scene` |
| `src/staff` | `engine`、`params`、`products` | `ui`、`scene` |
| `src/text` | 无 | 其他所有文件夹 |
| `src/ui`、`src/scene` | 上面所有 | |

两点说明：

- `src/engine` 里的函数不直接读取参数表，参数对象作为函数的参数传进去。这样测试时可以换一组参数。
- `src/engine` 不产生中文句子。它只产生"事件"（事件类型加数据），由界面把事件变成文字。

## 五、engine 对外接口的方向

完整的定义在 `docs/04-经营模型.md`。任务 01 只做下面这个占位的版本，任务 03 再换成完整的。

```ts
type Fulfillment = "cross" | "local";   // 跨境直发 | 本土店

interface GameConfig {
  seed: number;
  fulfillment: Fulfillment;   // 玩家开局时选，一局之内不变
  startCashFen: number;
}

interface GameState {
  config: GameConfig;
  day: number;             // 从 0 开始，每过一天加 1
  cashFen: number;         // 手里的现金，人民币分
}
```

三件一定要做到的事：

1. **按天推进。** 模型每天算一次，玩家每个季度做一次决定。
2. **可以重放。** 只要有种子和每个季度的决定，就能把一整局重新算出来，结果完全一样。
3. **每天产生事件列表。** 例如"来了 12 单""一批货到了""到账 ¥230.00"。界面靠事件列表来播放动画。

状态对象不可修改。每个函数都返回新的对象，不改动传进来的对象。

## 六、两种发货方式

游戏支持两种发货方式，用 `Fulfillment` 这个类型区分。玩家在开局时自己选，跨境直发中途可以升级成本土店。两者的区别见 `docs/04` 第 2.1 节。

凡是和费用、运输、到货时间有关的代码，都必须接收 `Fulfillment`，不能假设只有一种。

## 七、构建和发布

- 打包结果在 `dist/`，是纯静态文件。
- `vite.config.ts` 里设置 `base: "./"`，让网站放在任何路径下都能打开。
- 整个网站只有一个页面，不使用需要服务器配合的路由。
- 发布到 Qoder Sites，访问权限设为"任何人都可以访问"。
- 体积：`dist/` 里的 JS 压缩（gzip）后合计不超过 600 KB（其中 three.js 大约占 170 KB）。超过了要先说明原因。

## 八、画面尺寸

完整的画面规则见 `docs/08-画面规则.md`。下面是最基本的两条：

| 设备 | 窗口大小 | 要求 |
|---|---|---|
| 电脑 | 1440 × 800 | 一屏显示完，不需要上下滚动 |
| 手机 | 390 × 844 | 能正常使用，没有左右滚动 |

先保证电脑，再保证手机。风格干净、明亮，像一个新的 AI 产品。
