# 任务 09：打磨和发布

开始之前先读：`AGENTS.md`、`docs/01-项目框架.md` 第七节、`docs/08-画面规则.md`、`docs/11-检查机制.md`、`docs/13-检查员.md`。

任务 08 完成之后才做。这个任务不加新功能。

## 一、逐项检查并修好

1. **处理记下来的问题**：把 `检查记录/` 里所有检查记录的三级问题（`docs/11` 第六节）和"拿不准的"列出来，逐条处理或说明为什么不处理。
2. **完整走三局**：用 `?debug=1`，一局跨境直发，一局本土店，一局中途升级。现金等式的面板不能变红。
3. **画面**：`npm run check:full -- --task 09` 全部通过。把五种窗口大小的全部截图看一遍。
4. **文字**：没有错别字；没有残留的英文和占位文字；组件里没有直接写的中文；游戏里没有真实平台的名字。
5. **键盘**：Tab 能走到每个按钮和输入框，焦点看得见。
6. **减少动态效果**：开启后按 `docs/10` 第六节处理。
7. **断网**：加载完成后断网，能完整玩一局。
8. **体积和速度**：`dist/` 的 JS 压缩后不超过 600 KB。首屏在普通网络下 3 秒内出现。世界的帧率达到 `docs/10` 第十节的要求。关掉 WebGL 也能玩完一局。
9. **浏览器**：Chrome、Edge、Safari，再加一台手机，各玩过一个季度。
10. **页面标题和图标**：标题是"第一桶金"，有一个简单的图标（一个金色的圆）。
11. **README.md**：写清楚这是什么、怎么运行、目录、数据的来源等级。

3. 发布之后叫检查员做最后一次检查（`docs/13` 第五节）。`检查记录/进度表.md` 里每一行都是"通过"，才算可以提交作品。
