# 任务 06：界面（设计系统、世界、首页、开局、做决定）

开始之前先读：`AGENTS.md`、`docs/07` 到 `docs/13` 这七份、`参考图/说明.md`，并看 `参考图/` 里的四张图。画面的感觉以参考图为准，具体的规定以文档为准。

任务 05 完成之后才做。这个任务分三步。每一步做完都运行 `npm run check:full`、提交一次、叫检查员查一次（`docs/13` 第五节）。检查员通过之后，**还要等项目负责人看过截图、确认了，才做下一步**。

## 一、第一步：设计系统和角色

1. **依赖和文件结构**：`docs/12` 第一、二节。
2. **设计变量**：`docs/07` 第二节、`docs/08`、`docs/10` 第四节的颜色。写进 `src/ui/theme/tokens.ts` 和 Tailwind 的主题。
3. **基础组件**：`docs/09` 第 3.1 节的 12 个。
4. **三个角色**：`docs/10` 第三节，每人三个表情。
5. **展示页** `?gallery=1`：每个基础组件的每种变体和状态；三个角色的三种表情；印章。
6. **页面自检**：`docs/13` 第四节。这一步先做 S1、S3、S4、S7，其余的在第三步加上。
7. **截图脚本** `npm run shots`：`docs/11` 第四节。这一步只截展示页。接进自动检查的 K7。
8. **规则检查**：加上 `docs/11` 第 2.2 节的 R3 到 R10。

做完后把展示页的截图发给我。

## 二、第二步：世界

1. **世界**：`docs/10` 第一到五节。镜头、光、`docs/10` 第三节清单里的每一样模型、四个季节。
2. 在展示页里加一栏：每一样模型单独摆出来；一个按钮切换四个季节；一个按钮切换跨境直发和本土店；三个按钮切换库存的少、中、多。
3. **不支持 3D 时的替代图**：`docs/10` 第七节。
4. `?demo=season-0` 到 `season-3`。截图脚本加上这四个和展示页的世界那一栏。
5. 这一步世界里的东西先不动（动画在任务 07 做）。

做完后把四个季节的截图发给我。

## 三、第三步：首页、开局、做决定

1. **骨架**：`Stage`，`docs/12` 第三节。
2. **状态和数据流**：store 按 `docs/09` 第二节；动作和取数按 `docs/12` 第四节。每个动作都有测试。
3. **首页、开局**：`docs/07` 第三、四节。
4. **做决定**：时间线、状态、询价、三个角色和说话框、决定栏、主要按钮。布局按 `docs/07` 第四节和 `docs/08` 第二节。
5. **四个决定弹窗和推流分、数字从哪来两个弹窗**（P1 到 P5、P7）：`docs/09` 第四节。输入规则和提示按第五节。
6. **世界跟着数据变**：`docs/10` 第五节里和"做决定"有关的几项（发货方式、库存、路上的货、路上的货款、季节）。小牌子按 `docs/10` 第五节最后一段。
7. **体验**：`docs/12` 第 6.2 到 6.6 节里和这几个阶段有关的部分：沿用上个季度、全听他的、键盘、第 1 个季度只亮两格、点数字看解释、"预计花掉"。
8. 点主要按钮之后，这个任务里先直接算完这个季度（遇到大单货不够，先一律当作不处理），不播放、不结算，直接进入下一个季度的做决定。
9. `?demo=home`、`setup`、`decide` 和 6 个弹窗的 `?demo=popup-…`。截图脚本加上它们，并生成 `过程截图/自动/对照.html`（`docs/13` 第七节）。页面自检加上 S12、S13、S14，五个区、主要按钮、小牌子、角色都带上 `docs/13` 第四节的标记。
10. 所有文字放进 `src/text/zh.ts`，按 `docs/07` 第六节。

## 四、完成的标准

- `npm run check:full` 通过（`docs/11` 第 4.2 节的 S1 到 S14 里和已做部分有关的）。
- 三步的检查员结论都是通过。
- 1440 × 800 和 390 × 844 都符合 `docs/07`、`docs/08`。
- 能从首页一路点到第 8 个季度结束，中途不报错。
- `dist/` 的 JS 压缩后不超过 600 KB。
- 已经提交 git，`开发日志.md` 里有记录，已经重新发布，公开链接能打开。
