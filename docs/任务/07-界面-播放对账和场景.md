# 任务 07：界面（播放、提醒、大单货不够、季度结算、工作台）

开始之前先读：`AGENTS.md`、`docs/04` 第十六、十七节、`docs/07` 到 `docs/13`。

任务 06 完成之后才做。

## 一、要做的事

1. **播放**：`docs/07` 第四节"播放时"；`docs/12` 第四节"播放的做法"。一个季度 6 秒，可以跳过。
2. **世界动起来**：`docs/10` 第六节的动画，和第五节里播放时才有的几项（发货、到账、缺货、差评、延误、审核、封店、倒闭）。
3. **提醒**：`docs/07` 第 6.7 节。做决定时的提醒在进入这个阶段时算好；播放时的提醒跟着事件出现。计算放在 `src/staff/`，要有测试。所有提醒都记进 store，在工作台里能翻到。
4. **大单货不够**（弹窗 P9）：`docs/04` 第十六节、`docs/07` 第 6.8 节。播放到那一天停住，玩家选了才继续。选择要记进这个季度的决定里。
5. **季度结算**：播放结束后算账单，自动打开季度账单（弹窗 P6，`docs/09` 第四节）。没有确认账单时，主要按钮是灰的，旁边写明原因。确认之后说话框换成对账。
6. **"为什么"**：`docs/12` 第 6.4 节的 12 种原因。
7. **工作台**（弹窗 P8）：`docs/09` 第四节。三个页签，每一块的内容和状态标签。
8. **角色的表情**：结算时按 `docs/10` 第三节换表情：他的预测和"全听他的实际"相差不到一成是高兴；相差超过三成，或者他的方案试算时会倒闭、被封店，是为难；其余是平常。
9. **新手提示**：`docs/07` 第 6.6 节、`docs/12` 第 6.4 节。
10. 加上 `?demo=play`、`settle`、`popup-bill`、`popup-desk`、`popup-bulkshort` 和 `?debug=1`。截图脚本加上它们。`?debug=1` 的面板里同时显示现金等式和页面自检（`docs/13` 第四节）。
11. 去掉任务 06 第三步第 8 条的临时做法。

## 二、完成的标准

- `npm run check:full` 通过，包括 S9（每个弹窗能打开、能关上）和 S11（最长的内容）。
- 检查员的结论是通过（`docs/13` 第五节）。
- 测试：没确认账单时 `nextQuarter` 无效；播放遇到 `pending` 会停下，回答之后继续；把一局里实际做过的选择重放一遍，结果相同。
- `?debug=1` 下玩完一局，现金等式和页面自检一直没有变红；每个季度的账单都显示"已核对"。
- 一个季度的播放不卡顿。运行时没有任何网络请求。
- 两种尺寸都符合文档。`dist/` 的 JS 压缩后不超过 600 KB。
- 已经提交 git，已经重新发布。
