# 08 画面规则

> 第 2 版（2026-11-20）：前排从三个角色换成三个功能区，底部从"决定栏"换成现金计划。

这份文档规定画面上的硬性限制。每一屏放什么见 `docs/07`，有哪些组件见 `docs/09`，图形怎么画见 `docs/10`。

和 `docs/07` 有出入的地方，以本文为准。

## 一、支持哪些屏幕

| 类型 | 宽度 | 要求 |
|---|---|---|
| 电脑（设计基准） | 1440 × 800 | 整个画面一屏显示完，不上下滚动 |
| 电脑（支持范围） | 1280 到 1920 | 不错位。内容区最宽 1440，更宽的屏幕两边留空，居中 |
| 手机竖屏（设计基准） | 390 × 844 | 整个画面一屏显示完；只有弹窗里面可以上下滚动 |
| 手机竖屏（支持范围） | 360 到 430 | 不错位 |
| 平板横放和窄窗口 | 1024 到 1279 | 用电脑的布局，功能区变窄，不单独设计 |
| 小于 1024 | | 用手机的布局（规则包第 14 版：768 宽时功能区里面只有约 193 宽，放不下最长的决定"RM 19.90 · ¥0.34 · ¥130"，所以分界从 768 改成 1024） |
| 手机横屏 | | 不支持。显示一句"请把手机竖过来"，不显示游戏 |

整个页面任何时候都不滚动。高度不够时怎么办见第二节。

**不用整页缩放**（不用 `transform: scale` 把整个页面缩小来适应屏幕）。文字会变模糊。

## 二、屏幕分区

整个画面只有一屏。世界铺满整个画面，在最下面一层；界面的各个区盖在它上面，位置固定，互相不重叠。

电脑（1440 × 800 时的位置，单位是像素）：

| 区 | 左右 | 上下 | 内容 |
|---|---|---|---|
| 时间线 | 左 24 起 | 16 到 60 | 年、季度、季节、8 个点 |
| 状态 | 右 24 止 | 16 到 60 | 现金、库存、推流分、风险、"?" |
| 询价 | 右 24 止，宽 236 | 76 起 | 这个季度的询价单 |
| 世界的主体 | 居中 | 大约 70 到 482 | 世界里的两块地和海要落在这个范围里，不被界面盖住 |
| 前排 | 24 到 1416，三等分 | 492 到 696 | 三个功能区：进货、运营、财务 |
| 底部 | 24 到 1416 | 714 到 784 | 现金计划和主要按钮 |

- 窗口更宽：时间线和状态仍然贴两边，前排和底部最宽 1440 并居中，世界跟着变大。
- 窗口更矮（高度小于 720）：世界缩小，前排和底部不变。高度小于 640 时，功能区里"参考数字"那一行收起。
- 手机的分区见 `docs/07` 第五节。

## 三、网格和间距

- 间距只用这几个值（像素）：4、8、12、16、24、32、48。
- 电脑的内容区分 12 列，列间距 16。
- 卡片的内边距 16。卡片之间的间距 16。
- 同一行里的东西顶部对齐。数字右对齐，文字左对齐。

## 四、文字

字号只用这几个（像素）：

| 字号 | 用途 |
|---|---|
| 12 | 说明、单位、表头。**这是最小的字号** |
| 14 | 正文 |
| 16 | 卡片里的重点、按钮 |
| 20 | 卡片标题 |
| 28 | 屏的标题 |
| 40 | 一屏里最重要的数字（现金、净资产） |
| 56 | 首页标题 |

- 行高：文字 1.5，数字 1.2。
- 一行中文不超过 34 个字。超过就换行或缩短。
- 字重只用三种：正常、中等、最粗。不用斜体。

## 五、颜色

色值见 `docs/07` 第二节。再加一个：

| 名称 | 色值 | 用在哪 |
|---|---|---|
| `goldText` | `#8F6400` | 白底上表示钱的**文字**。`gold` 只用于图形和大于等于 28 的数字 |

使用规则：

1. 颜色的意思固定：`sea` 是货和可以点的东西，`gold` 是钱，`hibiscus` 是亏损和警告。不拿它们做装饰。
2. 文字和背景的对比度不低于 4.5 比 1。大于等于 28 的字不低于 3 比 1。`sea`、`hibiscus` 做小于 28 的字，或者做上面放小字的底色时，换成 `seaText`、`hibiscusText`（和 `gold`、`goldText` 一样）。禁用的控件不算（旁边写原因的字要算）。
3. 不只靠颜色传达意思。亏损除了变红，前面还要有负号；风险等级除了颜色，还要写"低、中、高"。
4. 一屏里 `hibiscus` 出现的地方不超过 3 处。到处都红，就没有人看了。
5. 不用渐变。不用半透明叠色做背景。弹窗后面变暗的那一层（`ink` 40%）是遮罩，不算背景。

## 六、数字怎么显示

| 类型 | 规则 | 例子 |
|---|---|---|
| 人民币 | `¥` 加千分位加两位小数 | ¥3,200.00 |
| 林吉特 | `RM` 加空格加两位小数 | RM 19.90 |
| 负的钱 | 负号放最前面，用 `hibiscusText`（大于等于 28 的数字可以用 `hibiscus`） | -¥20.87 |
| 售价 | 先写林吉特，后面用小一号的字写人民币 | RM 19.90（¥32.84） |
| 现金、成本、利润、净资产 | 只写人民币 | |
| 件数、单数 | 整数加单位 | 450 件、412 单 |
| 天数 | 整数 | 第 37 天 |
| 比例 | 一位小数加百分号 | 4.4% |
| 推流分 | 整数 | 72 |
| 变化 | 带正负号，放在括号里 | 72（+7） |

- 所有钱都用 `src/engine/money.ts` 的函数来显示，不在组件里自己拼。
- 数字变化时，位置不能跳动（用等宽数字）。

## 七、一屏能放多少

1. 全屏只有一个主要按钮（`gold` 色）。弹窗里的确认按钮用青色：底色 `seaText`、白字。
2. 一张卡片不超过 8 行。放不下就分两张，或者把次要的收起来。
3. 一屏里用 40 字号的数字不超过 2 个。
4. 提醒不超过 20 个字（数字和符号算半个字）。世界里的小牌子不超过 12 个字。数字和标签永远不换行。
5. 事件列表同时只显示最近 8 条。

## 八、层级

从下到上。数字是 `z-index`：

| 层 | 值 |
|---|---|
| 世界的画布 | 0 |
| 世界里的小牌子 | 5 |
| 时间线、状态、询价、前排、底部 | 10 |
| 功能区上方的提醒 | 15 |
| 弹窗后面的暗色 | 20 |
| 弹窗 | 30 |
| 新手提示、点数字的解释 | 40 |
| 印章盖下来的那一下 | 50 |

- 同一时间只开一个弹窗。不做"弹窗上面再弹窗"。
- 弹窗的规则见 `docs/09` 第四节。

## 九、动画的限制

界面上的动画见 `docs/09` 第六节，世界里的动画见 `docs/10` 第六节。限制：

1. 除了场景里持续移动的包裹和货款，任何动画不超过 0.4 秒。
2. 场景里同时在动的东西不超过 60 个。
3. 不做视差、不撒彩纸、不抖动、不闪烁。
4. 动画不能挡住操作。播放季度时可以随时跳过。
5. 没有任何声音。

## 十、操作

| 方式 | 要求 |
|---|---|
| 鼠标 | 可以点的东西，鼠标放上去有变化 |
| 触摸 | 可以点的区域不小于 44 × 44 |
| 键盘 | Tab 能按顺序走到每个可以操作的东西；焦点有 2 像素的 `sea` 色外框；回车等于点击；Esc 关闭面板 |

电脑上可以点的区域不小于 32 × 32（文字里点数字看解释的链接除外，见 `docs/11` S4）。

## 十一、性能

| 项目 | 上限 |
|---|---|
| `dist/` 里的 JS（gzip 压缩后） | 600 KB，其中 three.js 大约 170 KB |
| 字体文件 | 两个字重，合计 60 KB |
| 位图图片、外部的模型文件 | 不用 |
| 界面的页面元素（不含画布） | 1500 个 |
| 点击到有反应 | 0.1 秒 |
| 从点主要按钮到开始播放 | 0.5 秒 |
| 运行时的网络请求 | 0 个 |
| 世界的帧率和网格数量 | 见 `docs/10` 第十节 |

## 十二、不允许的

- 整页缩放。
- 左右滚动。
- 弹窗套弹窗。
- 自动播放的声音和视频。
- 从网上加载字体、图片、脚本。
- 只用颜色区分意思。
- 小于 12 的字。
- 把文字画进 3D 的世界里。
- 文字超出它的框、被截断、互相重叠。
- 在组件里直接写颜色值、间距值、中文。

## 十三、浏览器

Chrome、Edge、Safari、Firefox 的最近两个大版本。iPhone 的 Safari 16 以上。安卓的 Chrome。
