# 03 每单结算规则

## 一、范围和来源

这份文档只回答一个问题：**卖出一单，平台打给卖家多少钱，卖家这一单赚多少。**

- 来源：项目负责人指定的马来西亚站费率计算器（2026 年 9 月的费率）。来源等级是 B。
- 支持两种发货方式：跨境直发（`cross`）和本土店（`local`）。
- 不包含的内容见第十一节。

## 二、单位和取整

- 售价、平台的各项费用、平台打款：用仙（sen）。
- 进货成本、货代费、贴单费、利润：用人民币分（fen）。
- 比例用万分之几（bp）。
- **每一项费用单独算，算完立刻四舍五入成整数的仙。** 按比例的费用一律用 `applyBp`（见 `docs/02` 第一节）。

## 三、两种发货方式的区别

| 项目 | 跨境直发 `cross` | 本土店 `local` |
|---|---|---|
| 平台佣金率（默认） | 14.58% | 10% |
| 交易手续费率 | 3.78% | 3.78% |
| 手续费的计算基数里加上的运费 | 买家付的运费：西马 RM 2.90，东马 RM 8.00 | 配送费：西马 RM 4.90，东马 RM 10.00 |
| 平台支持费（每单固定） | RM 0.54 | RM 0.54 |
| 销售税 | 售价的 9.1% | 不扣 |
| 跨境运费（卖家承担） | 按重量算，见第五节 | 没有 |
| 平台运费（卖家承担） | 没有 | 配送费的 6% |
| 返现活动服务费 | 没有 | 参加时扣售价的 4.86%，不参加不扣 |
| 达人佣金 | 售价 × 达人佣金率 | 售价 × 达人佣金率 |
| 每单另付的人民币费用 | 货代和国内运费 ¥1.30 | 仓库贴单费 ¥2.00 |

说明：买家付的运费和配送费不是卖家的收入，也不是卖家的支出。它只用来计算交易手续费。

## 四、跨境直发：一单扣哪些钱

设售价为 `priceSen`，买家运费为 `buyerShippingSen`（西马 290，东马 800）。

| 费用 | 算法 |
|---|---|
| 平台佣金 `commissionSen` | `applyBp(priceSen, commissionBp)`，默认 `commissionBp` 是 1458 |
| 交易手续费 `transactionFeeSen` | `applyBp(priceSen + buyerShippingSen, 378)` |
| 平台支持费 `fixedFeeSen` | 54 |
| 销售税 `sstSen` | `applyBp(priceSen, 910)` |
| 跨境运费 `crossShippingSen` | 见第五节 |
| 达人佣金 `creatorFeeSen` | `applyBp(priceSen, creatorBp)`，默认 `creatorBp` 是 0 |
| 平台运费 `platformShippingSen` | 0 |
| 返现活动服务费 `cashbackFeeSen` | 0 |

## 五、跨境运费

30 克起算，之后每 10 克加一档，最后加 6% 的税。重量 `weightG` 是不小于 1 的整数。

```
steps   = weightG <= 30 ? 0 : Math.ceil((weightG - 30) / 10)
baseSen = 18 + 12 * steps
crossShippingSen = baseSen + applyBp(baseSen, 600)
```

核对表：

| 重量（克） | 1 | 30 | 31 | 40 | 50 | 51 | 100 | 101 | 200 | 250 | 300 | 500 | 1000 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 运费（仙） | 19 | 19 | 32 | 32 | 45 | 57 | 108 | 121 | 235 | 299 | 363 | 617 | 1253 |

## 六、本土店：一单扣哪些钱

设售价为 `priceSen`，配送费为 `deliveryFeeSen`（西马 490，东马 1000）。

| 费用 | 算法 |
|---|---|
| 平台佣金 `commissionSen` | `applyBp(priceSen, commissionBp)`，默认 `commissionBp` 是 1000 |
| 交易手续费 `transactionFeeSen` | `applyBp(priceSen + deliveryFeeSen, 378)` |
| 平台支持费 `fixedFeeSen` | 54 |
| 平台运费 `platformShippingSen` | `applyBp(deliveryFeeSen, 600)` |
| 返现活动服务费 `cashbackFeeSen` | 参加时 `applyBp(priceSen, 486)`，不参加时 0 |
| 达人佣金 `creatorFeeSen` | `applyBp(priceSen, creatorBp)` |
| 销售税 `sstSen` | 0 |
| 跨境运费 `crossShippingSen` | 0 |

## 七、平台打款和每单利润

```
totalFeeSen = commissionSen + transactionFeeSen + fixedFeeSen + sstSen
            + crossShippingSen + platformShippingSen + cashbackFeeSen + creatorFeeSen

payoutSen = priceSen - totalFeeSen          // 平台打款，可能是负数
payoutFen = senToFen(payoutSen, cnyPerRmE4)

perOrderFeeFen = 跨境直发时是货代费（130），本土店时是贴单费（200）

profitFen  = payoutFen - costFen - perOrderFeeFen - adsFen - otherFen
revenueFen = senToFen(priceSen, cnyPerRmE4)
marginBp   = revenueFen 为 0 时是 0，否则是 Math.round(profitFen * 10000 / revenueFen)
```

- `costFen`：这件商品的进货成本。
- `adsFen`：摊到这一单上的广告费。`otherFen`：其他费用。这两项默认是 0。

## 九、要写的函数

放在 `src/engine/settle.ts`。参数对象作为最后一个参数传进去。

```ts
interface SettleInput {
  fulfillment: "cross" | "local";
  priceSen: number;
  weightG: number;            // 本土店时不使用
  region: "west" | "east";
  creatorBp: number;          // 没有达人时传 0
  joinCashback: boolean;      // 只对本土店有效
  commissionBp?: number;      // 不传时用这种发货方式的默认值
}

interface SettleResult {
  commissionSen: number;
  transactionFeeSen: number;
  fixedFeeSen: number;
  sstSen: number;
  crossShippingSen: number;
  platformShippingSen: number;
  cashbackFeeSen: number;
  creatorFeeSen: number;
  totalFeeSen: number;
  payoutSen: number;
  payoutFen: number;
}

function crossShippingSen(weightG: number, params): number
function settleOrder(input: SettleInput, params): SettleResult

interface UnitProfitInput extends SettleInput {
  costFen: number;
  adsFen: number;
  otherFen: number;
}

interface UnitProfitResult {
  settle: SettleResult;
  perOrderFeeFen: number;
  revenueFen: number;
  profitFen: number;
  marginBp: number;
}

function unitProfit(input: UnitProfitInput, params): UnitProfitResult
```

输入不合法时抛出错误：`priceSen` 不是正整数，或 `weightG` 不是不小于 1 的整数（只在跨境直发时检查）。

### 10.4 必须成立的关系

用带种子的随机数生成 500 组合法的输入，每一组都要满足：

1. 每一项费用都是整数，并且不小于 0。
2. `totalFeeSen` 等于八项费用相加。
3. `priceSen` 等于 `totalFeeSen + payoutSen`。
4. 跨境直发时，`platformShippingSen` 和 `cashbackFeeSen` 是 0。本土店时，`sstSen` 和 `crossShippingSen` 是 0。

## 十一、这份规则不包含的内容

下面这些不在这份文档里，见 `docs/04-经营模型.md`：

- 一天来多少单。
- 广告怎么带来订单。游戏里广告是按天花钱的，不是每单固定金额。
- 退货、拒收、差评。
- 货从中国运到马来西亚仓库的费用和时间。
- 买家多少天收到货，货款多少天到账。

## 十二、和原计算器的差别

原计算器用小数一直算到最后，只在显示时四舍五入。本项目每一项费用都先四舍五入成整数的仙。所以同一单的结果，可能和原计算器相差 1 到 2 仙。这是有意的设计，不是错误。
